# Clima Web 🌤️

Página web que muestra el clima actual de cualquier ciudad del mundo.

## ¿Cómo funciona?

1. Escribe el nombre de una ciudad
2. Haz clic en "Buscar"
3. La página muestra la temperatura y descripción del clima en tiempo real
